# 服务器设置

## 一、安装 mqtt server

- sudo apt install mosquitto mosquitto-clients
- sudo systemctl status mosquitto

### 1.1 配置 mosquitto.conf

``` txt
persistence true
persistence_location /var/lib/mosquitto/

log_dest file /var/log/mosquitto/mosquitto.log

include_dir /etc/mosquitto/conf.d

allow_anonymous true

listener 1883 0.0.0.0
```

## 二、安装 emqx neuron

- tar -zxvf neuron-2.15.0-linux-amd64.tar.gz

### 2.1 配置 neuron.json

``` json
{
        "ip": "0.0.0.0",
        "port": 7000,
        "disable_auth": 0,
        "syslog_host": "",
        "syslog_port": 541,
        "sub_filter_error": 0,
        "modbus_simulator": {
                "port": 502
        }
}
```

- pm2 start ./neuron --name neuron
- pm2 save

## 三、配置串口

- dmesg | grep tty
- sudo usermod -aG dialout nucadmin
- newgrp dialout
- echo "Test" > /dev/ttyACM0
- pm2 kill
- pm2 resurrect
- pm2 restart pm2-logrotate
- pm2 flush
- pm2 set pm2-logrotate:max_size 100M
- pm2 set pm2-logrotate:interval 3600
